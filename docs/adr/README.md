# Kadath ADR 索引

当前目录中的 `0001 ~ 0008` 分别回答这些问题：

- `ADR-0001`：Kadath 为什么采用 `Zig + Rust` 双语言策略，以及两种语言各负责什么模块
- `ADR-0002`：Kadath 如何用 `zig build` 组织混合构建，以及 `modules/`、`abi/`、Rust workspace 如何布局
- `ADR-0003`：Zig 与 Rust 的正式跨语言边界如何定义，包括 `C ABI`、内存模式、错误码、线程语义与失败边界
- `ADR-0004`：`RHI` 应该抽象到什么粒度，以及它负责什么、不负责什么
- `ADR-0005`：世界模型首期对外采用什么语义，内部是否允许 `ECS / 数据导向` 优化，以及如何保留演进边界
- `ADR-0006`：Editor 与 Runtime 应如何分层，当前必须预留哪些生命周期、窗口与数据协议边界，以及哪些集成方式明确延后
- `ADR-0007`：Runtime 资源加载与完整资产管线如何分层，`M3` 极简打包负责到哪里，以及哪些导入 / 构建职责明确留给后续工具链
- `ADR-0008`：Runtime 主循环、固定 / 变步长分层、世界推进入口与后台任务同步点应如何组织

当前依赖链可概括为：

- `0001` 锁定语言分工
- `0002` 基于 `0001` 锁定混合工程构建与目录结构
- `0003` 基于 `0001` 和 `0002` 锁定跨语言契约
- `0004` 基于 `0001 ~ 0003` 锁定图形底层抽象边界
- `0005` 基于 `0001 ~ 0004` 锁定世界模型方向
- `0006` 基于 `0001 ~ 0005` 锁定 Editor / Runtime 容器边界、生命周期边界与数据协议边界
- `0007` 基于 `0001 ~ 0006` 锁定 Runtime 资源读取边界、`M3` 打包边界与完整资产管线的外部工具链归属
- `0008` 基于 `0001 ~ 0007` 锁定 Runtime 执行模型、固定步长模拟边界与后台结果回流时机
